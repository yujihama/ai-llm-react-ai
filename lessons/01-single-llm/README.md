# 実習編1 単純なLLM呼び出しによる監査評価

評価手続と架空の証跡を一度に渡し、根拠付きの評価と情報不足による保留を体験する120分の教材です。

## 開始する

1. [受講者ガイド](learner/実習編1_受講者ガイド.docx)を開き、講師指定のLLM実行環境を準備します。
2. `learner/initial` と `learner/supplement` の原資料を読み、人の判定を記録します。
3. `learner/inputs/case_A.txt` を全文コピーし、履歴・検索・保存メモリを使わない実行環境へ1回送信します。
4. 別の新規セッションで `case_B.txt`、さらに `case_B_plus.txt` を実行して比較します。
5. Aを追加で2回実行し、A1〜A3の揺れと正しさを分けて記録します。

毎回 `learner/record_template.txt` を複製して入力条件と出力全文を保存します。環境の情報分離を保証できない場合は、ガイドに従ってBを先に保存します。

## 収録物

| 場所 | 内容 |
| --- | --- |
| learner | 受講者ガイド、編集用原稿、完成入力3件、実行記録ひな形 |
| learner/initial | 評価手続P01、発注台帳、発注書3件、承認履歴、在任名簿 |
| learner/supplement | 手動で追加する購買承認権限規程 |
| instructor | 講師用ガイド、編集用原稿、期待結果、教材の保守用データ |
| prepare_inputs.py | 手続と証跡から完成入力を再構成するオフライン補助プログラム |

**LLMへ渡すのは指定された完成入力の本文だけです。** ガイド、解答、教材フォルダー全体、以前の回答は渡しません。Word版とテキスト版のガイドは同じ内容です。

## 実行範囲

モデル提供元やAPIキーに依存しない教材です。外部LLMへの接続、課金、認証情報の保存は行いません。画面での1回送信と、内部で厳密に1リクエストだけ実行することは区別し、確認できた範囲を記録します。

解答は証跡から定めた期待結果であり、特定モデルの実測回答ではありません。実施モデルの出力、時間、費用は実習時に記録してください。

## 入力の再構成

Python 3のある環境で、教材フォルダーから `python prepare_inputs.py` を実行します。標準ライブラリだけを使い、ネットワーク通信は行いません。既存の完成入力と違いがある場合は上書きせず停止します。教材を意図的に変更した場合のみ `python prepare_inputs.py --overwrite` で再構成し、講師用解答との整合を再確認します。

AとB補完は同じ入力です。Bは同じ本文から権限規程だけを除いたものです。これにより、資料以外の入力条件を揃えます。

## 教材の範囲

企業、人物、取引、規程はすべて架空です。金額基準やP01の判定区分は教材独自であり、法令や監査基準の要件を表すものではありません。
