# 実習編4 単一ReActによる監査評価

ケースCの評価中に見つかった不足に応じて、LLMが検索・原文取得・値の比較・条件別の終了を選ぶ150分の実習です。応用RAGの固定手順と、行動選択を含む反復処理を比較します。

## 実行方式

LLMは講師指定の環境を使います。受講者はモデルの行動JSONをローカル実行プログラムへそのまま渡し、観測結果を同じ会話へ返します。行動の選択はモデル、ファイルの転送とツール実行は受講者が担います。これは手動中継の演習で、自動API接続を実装したものではありません。

プログラムはPython 3標準ライブラリだけで動きます。APIキーや追加パッケージは不要で、外部サービスへ接続しません。

## 開始する

1. [受講者ガイド](learner/実習編4_受講者ガイド.docx)を開きます。
2. このフォルダーを作業場所として、次を実行します。

```powershell
python react_lab.py init --scenario learner/scenarios/C_same.json --out runs/my_same
```

3. `runs/my_same/next_prompt.txt` を新規LLM会話へ送り、返されたJSONをプレーンテキスト・UTF-8（BOMなし）の `action.json` として保存します。コードフェンスを含めません。
4. 次を実行して行動を処理します。

```powershell
python react_lab.py step --session runs/my_same --action action.json
```

5. `runs/my_same/latest_observation.txt` を同じLLM会話へ返します。モデルが次に返した行動JSONで `action.json` を更新し、手順4〜5を繰り返します。
6. `finish`を受理したら終了します。上限で停止した場合は未完了として記録し、モデルが保留判定を提出した場合と区別します。

**各手数でnext_prompt全文を同じ会話へ貼り直さないでください。** 全履歴を含む再構成版なので、履歴が重複します。初回、または別の空の会話への再開時だけ使い、通常の継続にはlatest_observationを返します。

## 比較する3条件

| 条件 | 初期の予算明細 | 追加証跡の取得 | 学ぶこと |
| --- | --- | --- | --- |
| C_same | 提示済み | 利用可能 | 前編と同じ証跡で規程の不足を解消する |
| C_deferred | 未提示 | 利用可能 | 規程の適用中に気付いた予算情報を追加取得する |
| C_unavailable | 未提示 | この実行からは取得不可 | 取得できない条件を保留し、確認済み条件を維持する |

後の条件ではscenarioとoutを変更して新しい実行を始め、LLM会話も分けます。モデルへシナリオ設定や上の表を添付しません。取引・規程・証跡の内容は同じで、提示とアクセス可能性だけが異なります。

固定手順の対照は `learner/fixed_rag` にあります。前編の通常検索＋親の条＋明示参照の結果を固定入力に追加したものです。`C_same.txt` は前編の完成入力と完全一致。残る2条件は予算明細だけを除去した同一入力です。それぞれ独立したLLM会話で1回評価します。

固定側の出力は表、ReAct側はJSONで、指示と生成回数も異なります。判定内容は共通の4条件で比較しますが、形式エラー・文字数・時間の差を行動選択だけの効果とは扱いません。

## 収録物

| 場所 | 内容 |
| --- | --- |
| learner | 受講者ガイド、編集用原稿、エージェント指示、記録ひな形、行動JSONの書式例 |
| learner/procedures | C1〜C4の基準を保持し、実行方式を改版した手続 |
| learner/evidence/C | 前編と同じ取引・委任・予算・在任の証跡 |
| learner/corpus | 規程と、各シナリオから参照できる追加証跡 |
| learner/scenarios | 初期資料・ツールの参照範囲・10手の上限の設定 |
| learner/fixed_rag | 応用RAGの固定手順による対照入力 |
| instructor | 講師用ガイド、期待結果、必要根拠、検証例と確認記録 |
| basic_retrieve.py | 前編と同じ文字bigram TF-IDF検索 |
| react_lab.py | 行動JSONを受け取り、ツール観測と単一の履歴を管理する実行部 |

`state.json`、シナリオ設定、索引、資料フォルダー全体、講師用解答をモデルへ渡しません。必要な本文は初期入力またはツール観測を通じて届けます。

講師向けの[実行例と測定結果](instructor/examples/README.md)には、事前記述の再生3例とLLMによる行動選択2例を分けて収録しています。[モデル選択例の内容照合](instructor/model_result_review.md)も参照できます。いずれも評価途中のLLMへは渡しません。

## 評価の注意

検索0件や読取失敗は、この実行で取得できなかった観測です。資料の不存在や監査上の不備を直接証明しません。compareの一致も、モデルが値を正しく抽出したことや、規程が適用できることを保証しません。

取得可能な資料を調べず早期に保留した場合、根拠のない断定を避けた点と、取得を完了しなかった点を別々に評価します。行動順は一つの正解に固定せず、根拠の充足、適切な追加取得、停止、費用・文脈量を比較します。

教材の架空事例は、実務一般の承認金額基準を示すものではありません。最終的な監査意見や統制全体の有効性を結論する範囲は含みません。
