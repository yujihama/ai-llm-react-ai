# 実習編3 応用RAGによる監査評価

前回と同じケースCで、断片検索から親の条の復元、明示参照先の取得へ進む120分の実習です。適用条件・委任例外を原文で取得し、基本RAGと比較します。

## 開始する

1. [受講者ガイド](learner/実習編3_受講者ガイド.docx)を開きます。
2. このフォルダーで `python run_examples.py` を実行します。Python 3の標準ライブラリだけで動きます。
3. `runs/C_basic/prompt.txt` を講師指定のLLM環境へ一度送り、結果を保存します。
4. `C_parent`、`C_linked`、`C_basic_k5` のpromptを、それぞれ独立した新規セッションで評価します。
5. `C_limited` のログを観察し、取得上限により届かなかった情報を確認します。
6. 追加演習では `C_exception_basic` と `C_exception_parent` を比較します。

**送信するのは指定されたprompt本文だけです。** ガイド、索引、構造マップ、講師用解答、以前の回答を添付しません。モデル側の追加検索・接続資料・保存メモリを無効にし、同じ設定で比較します。

Pythonを使えない場合は `samples` にある実行済み検索結果を利用できます。これは実際の検索・文脈取得の出力であり、LLMの回答例ではありません。標準は4回のLLM送信、追加演習の評価は任意です。

## 比較条件

| ID | 検索語 | k | 取得方式 | 文脈単位数の上限 |
| --- | --- | ---: | --- | ---: |
| C_basic | 通常 | 1 | 固定400文字の断片 | 適用なし |
| C_parent | 通常 | 1 | 重なる条を全文で復元 | 20 |
| C_linked | 通常 | 1 | 親の条と明示参照先 | 20 |
| C_basic_k5 | 通常 | 5 | 固定400文字の断片 | 適用なし |
| C_exception_basic | 例外 | 1 | 固定400文字の断片 | 適用なし |
| C_exception_parent | 例外 | 1 | 重なる条を全文で復元 | 20 |
| C_limited | 通常 | 1 | 親の条と明示参照先 | 3 |

通常の検索語は「設備部 購買 承認 権限 税抜 発注」、例外の検索語は「設備更新 発注 委任例外 部長 承認 第5条」です。例外の検索語は人が指定する別系列で、自律的に生成した検索語ではありません。チャンクの重なりは全条件0です。

## 条件を変えて試す

1条件だけ実行する場合は `python run_examples.py --only C_linked` を使います。

個別実行の例です。クエリ・k・方式・取得上限のうち、一つだけを変更して別の出力先へ保存します。

```powershell
python advanced_retrieve.py --corpus learner/corpus/C --base learner/base/case_C.txt --query "設備部 購買 承認 権限 税抜 発注" --chunk-size 400 --overlap 0 --top-k 1 --structure learner/structure.json --mode linked --max-sections 20 --out runs/my_linked
```

既存の出力と異なる場合は停止します。意図して置き換える場合だけ `--overwrite` を指定します。原文の改訂後にハッシュが不一致になった場合は、条の範囲と参照を再確認して構造マップを更新します。ハッシュだけを置き換えて位置の確認を省かないでください。

## 比較の範囲

取引・評価基準・直接証跡・規程・固定指示は前編と同じです。入力内の実習2運用版という表示も比較のため保持しています。応用方式で変えるのは、取得後に文脈を戻す処理です。基本検索の順位や索引に正解表を使っていません。

基本RAGは検索順位順、応用RAGは文書・原文順に本文を提示します。LLMの回答の差には、情報の十分性だけでなく提示順・形式も関与し得ます。必要なら全文対照も用い、単一ケースから他の資料やモデルの改善率を一般化しません。

プログラムは外部LLMに接続しません。検索と文脈取得は実測済みですが、解答は証跡から定めた期待結果です。条文が揃っても、個別証跡との照合と人のレビューは必要です。
