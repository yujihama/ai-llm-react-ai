# 実習編2 基本RAGによる監査評価

前回の情報不足ケースへ外部資料の検索を追加し、その効果と、断片から前提・例外が欠ける限界を体験する120分の教材です。

## 開始する

1. [受講者ガイド](learner/実習編2_受講者ガイド.docx)を開きます。
2. このフォルダーで `python run_examples.py` を実行します。Python 3の標準ライブラリだけで動作します。
3. `learner/base/case_B.txt` を講師指定のLLM環境へ単発で送信し、検索なしの結果を保存します。
4. `runs/B_k1/prompt.txt` を独立した新しいセッションへ送り、検索で規程を追加した結果と比較します。
5. `C_k1`、`C_exception_k1`、`C_k3` のpromptを別々に評価し、前提と例外が揃ったか調べます。
6. `learner/controls/C_full.txt` を評価し、原文を人が追加した対照と比べます。`C_k5`の評価は追加演習です。

**LLMへ渡すのは指定されたprompt本文だけです。** ガイド、教材一式、instructor、index.json、前の回答は渡しません。index.jsonには未取得の原文も含まれます。

Pythonを実行できない場合は、`samples`にある実行済み検索結果で観察できます。これらは実際の検索出力ですが、LLMの回答例ではありません。自分での実行と区別して記録してください。

## 収録物

| 場所 | 内容 |
| --- | --- |
| learner | 受講者ガイドと編集用原稿、実験条件、記録用ひな形、検索方式の定義 |
| learner/base | 検索結果を付ける前の固定入力。規程は含まない |
| learner/corpus/B | 前回3件用の権限規程と検索対象の案内資料 |
| learner/corpus/C | 原則・適用条件・例外が離れた規程と案内資料 |
| learner/evidence | BとCの取引証跡。Cには委任書と予算明細も含む |
| learner/controls | 規程全文を手動で渡す比較用入力 |
| samples | 検索を実行して保存した索引、順位、取得断片、完成入力 |
| instructor | 講師用ガイド、全文の期待結果、必要根拠、検索の実測と保守用データ |
| retrieve.py | 固定文字分割と文字bigram TF-IDF検索 |
| run_examples.py | learner/experiments.jsonに定めた比較条件を実行 |

## 条件を変えて試す

1条件だけなら `python run_examples.py --only C_k3` を実行します。標準のクエリ・分割長・重なり・kは `learner/experiments.json` で確認できます。

個別の検索例です。

```powershell
python retrieve.py --corpus learner/corpus/C --base learner/base/case_C.txt --query "設備部 購買 承認 権限 税抜 発注" --chunk-size 400 --top-k 3 --out runs/my_C_k3
```

比較時はクエリ・分割長・重なり・kのうち一つだけを変えます。出力は別のフォルダーへ保存します。既存内容と差があると標準では停止し、意図して更新するときだけ `--overwrite` を使います。

## 実行と評価の範囲

プログラムは検索とLLM入力文の作成までを実行し、外部LLMへ接続しません。APIキーや追加パッケージは不要です。検索結果は実測済みですが、解答は教材の証跡から定めた期待結果であり、特定モデルでの回答性能を保証するものではありません。

検索は語句由来の疎ベクトルです。学習済みモデルの意味埋め込みと区別し、検索スコアを正しさの確率として扱いません。

Bの手続条件と取引証跡は前回を保持しています。Cは独立した追加ケースです。企業・人物・規程・取引は架空で、金額基準や判定区分は教材独自です。
