## 学習の流れ

1. **単純なLLM呼び出し**：評価手続と証跡を入力して評価する。
2. **基本RAG**：入力に含まれない社内規程や証跡を検索する。
3. **文脈を保つ応用RAG**：条件・例外・版・適用時点を含めて根拠を取得する。
4. **単一ReAct**：観測結果に応じて次の検索・照合・保留を選択する。
5. **サブエージェント**：調査ごとに文脈を分け、根拠付きの部分結果を統合する。
6. **総合比較**：品質、根拠の追跡可能性、費用、レビュー負担から必要十分な構成を選ぶ。

各段階では「実行 → 成功例 → 限界が現れるケース → 原因分析 → 改善 → 再評価」を繰り返します。共通の題材は架空の購買承認の監査評価です。

## 現在の収録範囲

理論編、実習教材の骨子、実習編1〜4を収録しています。各実習には評価手続、架空の証跡、入力資料、記録ひな形、講師用解答を含みます。実習編2・3には外部資料、実行可能な検索プログラム、実行済みの検索結果も収録しています。実習編3では原文の条と参照関係を使い、基本RAGとの比較と取得上限の影響を学びます。実習編4ではLLMが行動を選び、受講者がローカルツールとの受け渡しを行います。固定RAGとの対照入力、事前記述したツール再生例、LLMによる行動選択例を区別して収録しています。実習編5以降は今後作成する予定です。代表論文と一次資料への参照は各文書内に記載しています。

Word版は図表を含む閲覧・配布用、テキスト版は文章の編集と差分確認用です。理論編のテキスト版では図版を説明用の表記に置き換えています。
